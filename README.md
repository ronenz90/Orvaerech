# אור וערך לנעמה – אתר קישורים (GitHub Pages + Google Apps Script)

האתר עצמו סטטי ב-GitHub Pages. התוכן המשתנה (שורות, קישורים, טקסטים), הסיסמה והגלריה מנוהלים ע"י סקריפט Google קטן (`backend.gs`),
כך שעריכה מדף הניהול **לא** דורשת עדכון ריפוזיטורי.

## מבנה
- `index.html`, `css/style.css`, `js/main.js` – האתר. טוען את התוכן מהשרת; אם אין נתונים בשרת – מ-`data/site.json` (גיבוי/ברירת מחדל).
- `admin.html`, `js/admin.js`, `css/admin.css` – דף ניהול עם סיסמה. שומר לשרת.
- `backend.gs` – קוד ה-Apps Script (לא חלק מהאתר; מודבקים אותו ב-script.google.com).
- `js/config.js` – כתובת השרת (`SITE_API`).
- `assets/` – קלף, נוצה, לוגו וכותרות (חולצו מה-PDF של Canva).

## הגדרת השרת (Apps Script)
1. בפרויקט ה-Apps Script הקיים: מחליפים את כל הקוד בתוכן `backend.gs` ← שמירה.
2. **סיסמה:** Project Settings (גלגל שיניים) ← Script properties ← Add: `ADMIN_PASSWORD` = הסיסמה שבחרתם. הסיסמה נשמרת רק שם, לא בקוד ולא בריפוזיטורי.
3. Deploy ← Manage deployments ← עיפרון ← Version: **New version** ← Deploy. (הכתובת `/exec` נשארת זהה.)
4. מאשרים הרשאות בפעם הראשונה.

## דף הניהול
`.../admin.html` ← סיסמה ← עורכים ← "שמירה". השינוי חי מיד, בלי commit.
בכניסה הראשונה הנתונים נטענים מ-`data/site.json`; לוחצים "שמירה" פעם אחת כדי להעביר אותם לשרת.
אחרי 8 ניסיונות סיסמה שגויים הכניסה נחסמת ל-15 דקות. "הורדת גיבוי" מורידה עותק JSON.
התוכן נשמר בקובץ `naama-site-data.json` ב-My Drive (עם היסטוריית גרסאות של Drive).

## גלריה
נטענת מהשרת: כל התמונות בתיקיית ה-Drive (`FOLDER_ID` ב-`backend.gs`) ובכל תיקיות המשנה, עם הגדלה. עדכון תוך כ-10 דקות מהוספת תמונה.
