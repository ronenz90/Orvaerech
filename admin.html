חיבור ל-GitHub

כדי ששמירה תעדכן את האתר החי, צריך מפתח גישה (Personal Access Token). האתר כולו סטטי, לכן המפתח נשמר רק בדפדפן הזה ולא נשלח לאף מקום מלבד GitHub.

איך יוצרים Token?
  1. GitHub ← Settings ← Developer settings ← Personal access tokens ← Fine-grained tokens ← Generate new token.
  2. Repository access: Only select repositories ← בוחרים את ריפוזיטורי האתר.
  3. Permissions ← Repository permissions ← Contents: Read and write.
  4. מעתיקים את ה-Token ומדביקים כאן.
